# 추천·룰렛 제외 분류 필터 설계

## 목표

직원이 식당 분류를 여러 개 선택해 추천과 룰렛 후보에서 제외할 수 있게 한다. 예를 들어 `카페/간단식`을 제외하면 오늘 뭐 먹지와 룰렛 모두 해당 분류를 후보로 사용하지 않는다.

## 범위

- 추천 필터 UI에 다중 선택 제외 분류를 추가한다.
- 선택값을 URL 쿼리로 표현해 새로고침, 재추천, 룰렛 전환에도 유지한다.
- 서버의 추천 조건 검증과 추천 엔진에서 제외를 적용한다.
- 선택 가능한 값은 기존 식당 분류 목록만 사용한다.

## 제외 범위

- 사용자별 영구 저장 설정은 추가하지 않는다.
- 식당 데이터나 분류 체계는 변경하지 않는다.

## 데이터 흐름

1. 사용자가 필터에서 제외할 분류를 다중 선택한다.
2. 선택 목록은 `excludeCategories` 쿼리 값으로 직렬화된다.
3. 추천 페이지와 재추천·룰렛 서버 액션이 동일한 검증 스키마로 값을 해석한다.
4. 추천 엔진은 후보의 `category`가 제외 목록에 있으면 제거한다.
5. 룰렛은 같은 조건을 사용하므로 동일하게 제외한다.

## 오류 처리

- 허용되지 않은 분류나 잘못된 쿼리 형식은 기존 추천 조건 검증 실패로 처리한다.
- 제외 후 후보가 없으면 기존 빈 추천 안내를 표시한다.

## 검증

- 검증 함수: 다중 선택 파싱, 중복 제거, 잘못된 분류 거부.
- 추천 엔진: 제외 분류 후보가 결과에서 사라지는지 확인.
- URL/서버 액션: 재추천과 룰렛 URL에 선택값이 유지되는지 확인.
- 전체 lint, typecheck, test, build를 실행한다.
