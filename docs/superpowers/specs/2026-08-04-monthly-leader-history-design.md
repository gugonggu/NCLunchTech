# 월간 리더 기록 및 이달의 리더 배지 설계

## 목적

현재 월만 보여 주는 리더보드에 확정된 과거 월 기록을 추가한다. 매월 최고 합산 점수자를 `이달의 리더`로 기록하고, 해당 수상 배지를 프로필, 사용자 정보, 리뷰 작성자 정보에서 다른 직원도 볼 수 있게 한다.

## 범위

- 현재 월의 실시간 리더보드와, 서비스 시작 이후 모든 확정 월의 리더보드 조회
- 월별 순위와 수상 결과의 불변 스냅샷 보관
- 합산 1위의 `이달의 리더` 공개 배지와 수상 이력
- 리더보드, 프로필/사용자 정보, 리뷰 작성자 정보에서의 배지 표시

다음은 포함하지 않는다.

- 금전이나 상품 보상
- 연속 출석, 별도 경쟁 규칙, 기존 고정 업적의 변경
- 과거 확정 결과를 현재 활동 데이터로 다시 계산하거나 수정하는 기능

## 점수와 수상 규칙

집계는 Asia/Seoul 기준 한 달이다. 직원의 합산 점수는 다음 세 수치의 합이다.

```
리뷰 작성 수 + 새로 방문한 식당 수 + 메뉴 기록 수
```

- 현재 리더보드의 세 부문과 같은 원천 데이터를 사용한다.
- 새로 방문한 식당 수는 그 달에 완료된 방문 및 완료된 점심 약속에서 서로 다른 식당 수다.
- 합산 점수가 1점 이상인 직원만 월간 합산 순위에 포함한다.
- 가장 높은 합산 점수의 모든 동점자가 공동 1위이며, 모두 `이달의 리더` 수상자다.
- 수상은 월별 기록이며, 기존의 한 번만 획득하는 `achievements`/`user_achievements` 체계에 넣지 않는다.

## 데이터 모델

별도 월간 리더보드 스냅샷을 둔다.

### `monthly_leaderboard_periods`

한 행이 하나의 확정 월을 나타낸다.

- `month_key` (`YYYY-MM-01`, unique)
- `finalized_at`
- `created_at`

### `monthly_leaderboard_entries`

한 행이 확정 월의 한 직원 순위다.

- `period_id`
- `employee_id`
- `nickname_snapshot`
- `review_score`
- `explorer_score`
- `menu_score`
- `total_score`
- `rank`
- `is_monthly_leader`

닉네임을 함께 보존해, 직원이 닉네임을 바꾸거나 비활성화되어도 과거 기록이 당시 표시 그대로 남게 한다. `period_id`와 `employee_id`는 유일해야 한다.

## 확정 처리

- 매월 1일 00:00 이후 전월을 확정한다.
- 전월의 활동을 집계해 기간과 순위 행을 한 트랜잭션으로 만든다.
- 이미 확정된 월은 다시 계산하거나 덮어쓰지 않는다.
- 자동 처리가 누락된 경우, 리더보드 조회 시 지난 미확정 월을 오래된 달부터 같은 로직으로 보완한다.
- 동시 요청이 들어와도 unique 제약과 트랜잭션으로 한 번만 확정되도록 한다.
- 현재 월은 확정하지 않고 기존 원천 데이터로 실시간 집계한다.

## 화면과 공개 범위

### 리더보드

- 기본값은 현재 월이다.
- 월 선택기는 현재 월과 확정된 모든 월을 제공한다.
- 현재 월은 기존 세 부문별 순위를 유지하며, 합산 순위도 함께 보여 준다.
- 확정 월은 스냅샷의 합산 순위와 리뷰·새 식당·메뉴의 세부 점수를 보여 준다.
- 공동 1위에는 `이달의 리더`를 명확히 표시한다.

### 프로필과 사용자 정보

- 본인과 다른 직원 모두 가장 최근 `이달의 리더` 배지를 볼 수 있다.
- 예: `2026년 7월 이달의 리더`
- 수상자 프로필에는 받은 모든 월의 수상 이력을 월 단위 목록으로 표시한다.

### 리뷰

- 리뷰 작성자 닉네임 옆에 가장 최근의 월간 리더 배지 하나를 표시한다.
- 점수, 전체 수상 이력, 순위 세부 정보는 노출하지 않는다. 상세 정보는 리더보드의 해당 월에서만 본다.

## 오류 처리

- 스냅샷 조회에 실패하면 기존 현재 월 리더보드를 망가뜨리지 않고, 사용자에게 기록을 불러오지 못했다는 상태를 표시한다.
- 특정 과거 월이 확정되지 않았고 보완 처리에도 실패하면, 그 월은 선택 목록에 노출하지 않으며 오류를 기록한다.
- 활동이 전혀 없는 달도 확정 기간은 만들되 순위 행과 수상자는 만들지 않는다.

## 테스트

- Seoul 시간 월 경계 및 12월-1월 경계
- 리뷰, 고유 식당, 메뉴 기록을 합산하는 점수 계산
- 동점 공동 1위 및 활동 없는 달
- 확정 작업의 재실행과 동시 실행에서 중복 행이 생기지 않는지
- 확정 뒤 원천 활동, 직원 활성 상태, 닉네임이 바뀌어도 스냅샷이 변하지 않는지
- 현재 월과 과거 월 선택, 수상 표기, 리뷰의 최신 배지 표시

## 완료 기준

- 8월에 7월 리더보드를 선택해 확정된 7월 결과를 볼 수 있다.
- 7월 합산 공동 1위가 모두 `이달의 리더`로 표시된다.
- 수상자의 최신 배지는 프로필/사용자 정보와 리뷰에서 다른 직원에게 공개된다.
- 프로젝트의 `lint`, `typecheck`, `test`, `build`가 통과한다.
